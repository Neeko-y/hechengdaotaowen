# 长兴麻将（湖州长兴本地玩法）

一个纯前端、**本地单机**的湖州长兴麻将（白板做赖子）。当前为 **M1**：
牌桌 UI + 发牌 + 带赖子的胡牌判定 + 计分，**1 个真人 + 3 个简单机器人**。

规则详见 [`SPEC.md`](./SPEC.md)（唯一真源）。

## 运行

由于用了 ES Modules，**不能直接双击 `index.html`（file:// 会被浏览器 CORS 拦）**，请起一个本地静态服务器：

```bash
cd 麻将
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

> 联机时：房主用上面的命令起服务，其他人在**同一 WiFi** 下打开 `http://<房主局域网IP>:8000`（或扫房主页面的二维码）。

手机/桌面浏览器均可；手机端优先适配。

## 已实现（M1）

- 136 张牌、发牌、摸打、吃（仅上家）/ 碰 / 杠（明杠 / 暗杠 / 补杠）。
- 白板赖子：普通胡/杠开/特殊胡中为万能牌；**手里有白板只能自摸**；白板不能吃碰扛、但被打出后可用白板碰/杠。
- 胡牌判定：普通胡、七对、豪华七对、十三不搭、四白板、特殊胡、天胡；乱将。
- 计分：硬货自摸 6 / 有白板自摸 3 / 放炮 4·2·2 / 爆头 5 / 四白板 10 / 天胡 10 / 十三不搭 6；乘算倍率（杠开 ×2、七对 ×2、豪华七对再 ×2）。
- 一炮多响不允许：按逆时针离出牌者最近的一家胡。

## 联机对战（M2 · PeerJS P2P）

同一 WiFi 下 2–4 人玩（房主 + 最多 3 人；空位由电脑补）：

1. 房主打开页面 → **创建房间**，得到房间号 + 二维码。
2. 其他人同一 WiFi 打开同一网址 → **加入房间** 输房间号；或**扫码**直接进。
3. 房主点 **开始游戏**。

说明：

- 采用 **WebRTC P2P（PeerJS）**：不依赖自建服务器、不用注册账号。房主手机跑权威牌局，其余手机**直连房主**。
- 首次连接需**联网**完成信令握手（之后数据点对点）。PeerJS 已**内置**在 `vendor/peerjs.min.js`（不依赖 CDN）；二维码用公网图片服务生成。
- 房主只把你**自己的手牌**发给你，其他人只看到张数。
